Maze Explorer

Projeto em Python que gera labirintos aleatórios e a maquina tenta encontrar o caminho para a saída do labirinto.

Funcionalidades

- Geração de labirintos utilizando DFS.
- Resolução de labirintos utilizando BFS.
- Animações para visualizar a geração e a busca pelo caminho.
- Controles para pausar, retomar e ajustar a velocidade das animações.

Tecnologias utilizadas

- Python
- Tkinter
- Collections (deque)

Como funciona

O labirinto é criado utilizando o algoritmo Depth-First Search (DFS), que explora caminhos e remove paredes para formar passagens.

Para encontrar a saída, o projeto utiliza Breadth-First Search (BFS), que explora as posições por níveis e encontra o menor caminho possível.

A interface gráfica foi desenvolvida com Tkinter.

Como executar

É necessário ter Python instalado.

python3 maze_explorer.py

Objetivo

Projeto desenvolvido para praticar conceitos de algoritmos, estruturas de dados, geração procedural e busca em grafos.
